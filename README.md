# CF · CoverFlow

### Your music. Your desktop.

**A music-driven wallpaper app for macOS.**

Turn the artwork of your current track into a beautiful desktop background, with smooth transitions, a blurred color-matched backdrop, and an optional glass-style mini player.

## ✨ Features

- **Live album-art wallpapers** — a square cover centered on a blurred background based on the artwork.
- **Smooth transitions** — album artwork fades between tracks instead of switching abruptly.
- **Glass-style mini player** — compact controls near the bottom of the desktop, positioned left, center, or right.
- **Personalize the visualizer** — choose animated bars or import your own GIF.
- **Quick settings** — change the artwork size and player position from the macOS menu bar.
- **Wallpaper restoration** — restore the previous desktop background when exiting normally.
- **Music sources** — Spotify, Apple Music, and **Yandex Music in Safari** (the Safari integration is experimental).

## 📥 Download & install

> **The first downloadable release is being prepared.** The `Releases` page will contain the `.dmg` installer once it has been uploaded.

1. Download the latest `CoverFlow-Installer.dmg` from [Releases](https://github.com/raw228911/CoverFlow/releases) **when available**.
2. Open the DMG and drag **CoverFlow.app** into **Applications**.
3. Open CoverFlow from Applications.
4. Grant macOS permissions for music-app automation when requested.
5. Use the **CF menu-bar icon** to choose a music source and wallpaper mode.

### Important macOS security note

Early builds are **not Developer ID signed or notarized**. macOS Gatekeeper may warn about an unidentified developer or prevent launch. Only install files you trust. Future releases should be signed and notarized before broad distribution.

### Yandex Music

The Yandex Music integration currently uses **Safari**, not the standalone Yandex Music macOS app. To enable it, open the Yandex Music website in Safari and enable **Develop → Allow JavaScript from Apple Events**. This grants automation access to Safari, so use it only if you understand and trust the scripts requesting it.

## 🎨 Display modes

| Mode | Description |
| --- | --- |
| **Cover** | Square album art centered on a blurred, color-matched wallpaper; adjustable size |
| **Player** | Blurred wallpaper with a compact glass-style music panel near the bottom |

The visualizer bars are decorative animations rather than a measurement of the actual audio frequencies. A custom GIF can replace them.
